FIX 1 — SHAKE TO SOS
═══════════════════════════════════════════
Use expo-sensors Accelerometer to detect violent shake and 
trigger SOS automatically.

Implementation in HomeScreen.js:

import { Accelerometer } from 'expo-sensors'
import * as Haptics from 'expo-haptics'

useEffect(() => {
  Accelerometer.setUpdateInterval(300)
  const subscription = Accelerometer.addListener(({ x, y, z }) => {
    const acceleration = Math.sqrt(x * x + y * y + z * z)
    if (acceleration > 2.8) {
      Haptics.notificationAsync(Haptics.NotificationFeedbackType.Warning)
      triggerSOSCountdown()
    }
  })
  return () => subscription.remove()
}, [])

- Only trigger if SOS countdown is NOT already active 
  (add a ref flag: isSOSActive)
- Show a small shake indicator on home screen: 
  "Shake violently to trigger SOS" in small muted text 
  below the SOS button
- Works alongside the existing hold-to-SOS button
